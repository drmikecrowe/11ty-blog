{{- /* Code block render hook. Keeps Chroma highlighting AND its per-line wrappers intact (those wrappers are the line boundaries the site renders from and that Medium's importer reads — removing them collapses the block to one line in Medium and double-spaces it on-site). The only adjustment: when a line's final token is colored, Chroma puts that line's newline INSIDE the color span. Medium strips color spans and loses the newline, collapsing continued (\) lines. Move the newline just outside the color span so it sits in the same place as every normal line's newline (inside the flex wrapper) — on-site spacing is identical, Medium keeps the break. */ -}} {{- $code := trim .Inner "\n" -}} {{- $out := transform.Highlight $code .Type .Options | string -}} {{- $out = replaceRE "\n" "\n" $out -}} {{- $out | safeHTML -}}
