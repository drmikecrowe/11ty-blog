{{- /* Code block render hook. Keeps Chroma syntax highlighting (the rendered site is visually unchanged) but normalizes whitespace so Medium's "Import a story" scraper behaves: 1. Strip leading/trailing blank lines. Chroma's trailing newline otherwise imports as a stray empty code block. 2. Replace blank interior lines with a single space, so Medium keeps the blank line instead of dropping it. Note: we deliberately do NOT move newlines outside Chroma's per-line wrappers. Those wrappers already create the line break, so a loose newline beside them double-spaces every line on the site. */ -}} {{- $code := trim .Inner "\n" -}} {{- $code = replaceRE `(?m)^[ \t]*$` " " $code -}} {{- transform.Highlight $code .Type .Options -}}
