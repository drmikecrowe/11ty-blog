{{- /* Code block render hook. Keeps Chroma syntax highlighting (the rendered site is visually unchanged) but normalizes the HTML so Medium's "Import a story" scraper handles the block cleanly. Three fixes, all whitespace-only inside 
:

    1. Strip leading/trailing blank lines. Chroma's trailing newline otherwise
       imports as a stray empty code block.
    2. Replace blank interior lines with a single space. Medium drops truly
       empty lines and can split the block at them.
    3. Move each line's terminating newline OUTSIDE the closing  tags.
       Chroma tokenizes a line-continuation "\" with the newline inside a color
       span (\); Medium flattens that
       inline span and loses the newline, collapsing the two lines into one.
       Pushing the newline past the span closers keeps it as plain text.
*/ -}}

{{- $code = replaceRE `(?m)^[ \t]*$` " " $code -}}
