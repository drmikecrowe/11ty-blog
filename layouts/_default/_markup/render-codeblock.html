{{- /* Code block render hook. Keeps Chroma syntax highlighting for the site (the colored token s are preserved), but flattens Chroma's per-line wrapper spans so the markup is just colored tokens separated by REAL newlines inside 
.

  Why: Medium's "Import a story" scraper re-highlights code itself (highlight.js)
  and only needs clean text + line breaks. It mis-extracts text from Chroma's
  nested per-line  wrappers (values jump lines).
  A flat token stream with real newlines extracts cleanly. The site is visually
  unchanged because 
 already breaks on the newlines.

  Steps:
    1. trim leading/trailing blank lines (Chroma's trailing newline imports as a
       stray empty code block).
    2. blank interior lines -> a single space (Medium drops truly-empty lines).
    3. remove the inter-line "" boundaries, the first
       line opener, and the final line closer -> leaves tokens + newlines.
    4. move any line-final newline out of a trailing color span so the newline is
       plain text (Medium otherwise loses it, collapsing continued lines).
*/ -}}
{{- $code := trim .Inner "\n" -}}
{{- $code = replaceRE `(?m)^[ \t]*$` " " $code -}}
{{- $out := transform.Highlight $code .Type .Options | string -}}
{{- $out = replaceRE `` "" $out -}}
{{- $out = replaceRE `` "" $out -}}
{{- $out = replaceRE `` "" $out -}}
{{- $out = replaceRE "\n" "\n" $out -}}
{{- $out | safeHTML -}}
